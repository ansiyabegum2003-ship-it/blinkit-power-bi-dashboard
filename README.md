 **Blinkit Sales Analysis Dashboard | Power BI**

## Project Overview
This project uses Microsoft Power BI to analyze Blinkit sales performance and present business insights through an interactive dashboard.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Key Performance Indicators (KPIs)
- Total Sales
- Average Sales
- Number of Items
- Average Rating

## Dashboard Analysis
- Sales performance by item category
- Outlet size and location analysis
- Outlet establishment trends
- Product-level sales insights

## Skills Demonstrated
- KPI cards and data visualization
- Dashboard design and formatting
- Business analysis and reporting

## Project File
Download `Blinkit Project.pbix` from this repository and open it using Microsoft Power BI Desktop.
